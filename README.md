# GraphicGuard AI Agent

مساعد الهوية البصرية باستخدام HTML وFlask (Python).

## النشر على Vercel
1. ارفعي الملفات والمجلدات إلى جذر مستودع GitHub (وليس ملف ZIP نفسه).
2. في Vercel اختاري Add New > Project، ثم استوردي المستودع.
3. Framework Preset: Other أو اتركي الكشف التلقائي. Root Directory: جذر المشروع (فارغ).
4. Deploy. سيُنشئ Vercel رابطًا للمشروع.

## تجربة محلية
`pip install -r requirements.txt`
`python api/index.py`

ثم افتحي http://127.0.0.1:5000
